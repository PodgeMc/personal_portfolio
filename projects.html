Pi Control Panel V5

Flutter / Server Control

A cross-platform Flutter app built to monitor and control my Raspberry Pi server setup. It connects to a Python backend running on the Pi and gives me live status checks, service controls, storage monitoring, media import progress, and system information from desktop or mobile.

The app can check Plex, the hosted website, connected storage drives, and system health. It can also restart Plex, restart the website, start media imports, and connect locally or remotely through Tailscale.
