Home Server Project

Raspberry Pi Plex Media Server

A self-hosted media server built on a Raspberry Pi, designed for local streaming, remote access, organised storage, and a cleaner workflow for importing and managing media. Over time, the project expanded beyond Plex into a broader home server setup that also includes website hosting, automation, and custom management tools.

Raspberry Pi Plex Linux Nginx Python Automation

Project Overview

This project started as a way to build a low-power home media server that could run continuously, organise films and TV content, and stream media more conveniently than manually browsing files. It later became a more complete multi-purpose Raspberry Pi setup that also hosts a website, supports remote access, and uses automation to improve the overall workflow.

What makes this project stand out is that it combines hardware setup, Linux server administration, media organisation, storage management, scripting, and Python tooling into one practical system.

Key Features

Media Streaming

Organises and streams films and TV content through a clean media library interface.

Remote Access

Designed so the server can be reached and managed beyond the local network.

USB Import Workflow

Uses a transfer-drive process to move new media into the correct library locations.

Custom Management Tool

A Python desktop utility was built to make common server tasks easier to control.

What the System Does

  • Hosts a Plex media library for films and TV shows

Plex Setup and Library Structure

Plex Media Server was configured on the Raspberry Pi to organise and stream a personal media collection through a cleaner interface than raw file browsing. Instead of manually navigating folders, Plex provides posters, metadata, categories, and a more polished viewing experience.

The server libraries were organised into separate areas for films and TV content. Keeping the storage structured properly improves library management and helps Plex recognise content more reliably.

Website Hosting on the Same Raspberry Pi

One of the more interesting parts of this project is that the Raspberry Pi is not only used for media streaming. It also hosts my portfolio website using Nginx. Running both services on the same machine gave me more hands-on experience with Linux server setup and helped me better understand how multiple services can coexist on one device.

This made the project more than just a Plex install. It became a real home server environment that I actively manage and improve.

USB Media Transfer Workflow

To make the process of adding new content cleaner, I designed a USB transfer workflow. New files can be prepared on a separate drive and then imported into the server rather than managing the main storage directly every time.

Step 1

Place new films or TV episodes onto the transfer drive in the correct folder structure.

Step 2

Connect the transfer drive to the Raspberry Pi when new content needs to be imported.

Step 3

Run the import process so files are copied to the correct library locations automatically.

Step 4

Refresh or rescan content so the new media appears correctly in the library.

Automation Script

A script was created to automate the media import workflow. Instead of manually moving files every time, the script checks that the transfer drive is available, copies content into the correct locations, avoids unnecessary overwrites, and can show transfer progress.

This made the server feel much more complete and practical to use. It also reduced repetitive manual work and lowered the chance of mistakes during larger imports.

Custom Management Tool

To improve day-to-day usability, I created a Python-based management application that could control common server tasks from another computer. This was useful because it removed the need to manually type the same commands repeatedly into a terminal.

  • Open Plex quickly from another machine
  • Open the hosted website
  • Trigger media imports
  • Copy website files between the Raspberry Pi and a PC
  • Check service status
  • Open an SSH session
  • Restart or shut down the Raspberry Pi

Building this tool added another layer to the project by combining server administration with desktop Python development.

Challenges and Problem Solving

Power Stability

Power issues caused instability early on, which affected storage reliability and transfers. Improving the power setup made the system more dependable.

Changing Local Address

The server originally received changing network details after reboot, which caused connection problems. Fixing that made access much more reliable.

USB Mounting

The transfer drive did not always behave perfectly, so the import process had to account for mounting issues and edge cases.

Library Refreshing

Some imported files needed a manual refresh before appearing in the media library, which highlighted the need for better automation.

Future Direction

One of my long-term goals is to move beyond Plex and build a more custom private streaming platform for personal use. The current Plex server works well as a foundation, but I would like more control over the user experience, interface design, features, and overall workflow.

The idea would be to gradually evolve this project into a fully customisable streaming service with its own front end, media organisation system, and private features designed around how I want the platform to behave. That would turn the project from a self-hosted media server into something closer to a complete custom streaming platform.
